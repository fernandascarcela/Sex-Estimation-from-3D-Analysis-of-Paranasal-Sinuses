# Estimativa de Sexo com Inteligência Artificial Aplicada à Análise Tridimensional da Região Orbitária

Sistema desenvolvido para auxiliar na identificação do sexo biológico por meio da análise automática de imagens de Tomografia Computadorizada (TC) utilizando técnicas de Inteligência Artificial, Visão Computacional e Deep Learning.

O projeto explora arquiteturas de Redes Neurais Convolucionais (CNNs) e métodos de Transfer Learning aplicados à análise tridimensional de estruturas craniofaciais, com foco na região orbitária e seios paranasais. O sistema foi desenvolvido com o objetivo de apoiar pesquisas nas áreas de computação aplicada à saúde e antropologia forense.

Os experimentos realizados alcançaram resultados promissores, incluindo acurácia de 92,60% utilizando ResNet50 combinada com Random Forest.

## Tecnologias Utilizadas

* Python
* PyTorch
* MONAI
* Scikit-learn
